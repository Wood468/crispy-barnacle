Transparency & methodology

Event sources

How event information is collected, and how to interpret details that have not been confirmed.

How event information is handled

  • Official announcements are preferred for dates, bonuses, research, moves, tickets and event conditions.
  • Community sources help with calendars, graphics and useful context. They are labelled as community sources rather than presented as official announcements.
  • Unconfirmed details stay unconfirmed. An absent announcement does not mean an encounter, bonus, raid or feature is impossible—or that it definitely will not happen.
  • Conflicting reports are not silently combined. When sources disagree, check the in-game event information before making plans.
  • Times are local unless noted otherwise. In-person events may use destination-local time; check the timezone label and official event page.

Event data can change after publication. Check the linked source and in-game event page before travelling or relying on a deadline.

Principal sources

  • Pokémon GO — official news: primary announcements and event rules.
  • Pokémon GO Hub: event coverage, research and community reporting.
  • Leek Duck — events: event calendars and visual guides.
  • PokeCoord: credited community graphics and event guides where linked.
  • Poketools: raid attacker reference data.

Specific event pages should link to the source used for their details and graphics. Source attribution does not imply endorsement or affiliation.
